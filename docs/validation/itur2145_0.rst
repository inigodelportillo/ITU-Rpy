Validation results ITU-R P.2145-0
=================================

This page contains the validation examples for Recommendation ITU-R P.2145-0: Digital maps related to the calculation of gaseous attenuation and related effects.

All test cases were extracted from the
`ITU Validation examples file (rev 5.1) <https://www.itu.int/en/ITU-R/study-groups/rsg3/ionotropospheric/CG-3M3J-13-ValEx-Rev5_1.xlsx>`_.

.. contents:: Functions tested
    :depth: 2


Function barometric_surface_pressure
------------------------------------

The table below contains the results of testing function ``barometric_surface_pressure``.
The test cases were extracted from spreadsheet ``ITURP2145-0_barometric_surface_pressure.csv`` from the
`ITU Validation examples file (rev 5.1) <https://www.itu.int/en/ITU-R/study-groups/rsg3/ionotropospheric/CG-3M3J-13-ValEx-Rev5_1.xlsx>`_.
In addition to the input-arguments, expected result (``ITU Validation``), and
ITU-Rpy computed result (``ITUR-py Result``), the absolute and relative errors
are shown. Each test case is color-coded depending on the magnitude of the
errors (green = pass, errors are negligible, red = fail, relative error is
above 0.01%).

In addition, the code snippet below shows an example of how to generate the
first row of the results in the table:

.. code-block:: python

    import itur

    # Define input attributes
    lat = 0.0  #  (?N)
    lon = 0.0  # (?E)
    alt = 0.0  # (km)
    p = 0.1  # (%)

    # Make call to test-function barometric_surface_pressure
    itur_val = itur.models.itu2145.barometric_surface_pressure(lat=lat, lon=lon, alt=alt, p=p)

    # Compute error with respect to value in ITU example file
    ITU_example_val = 1018.364832  # (hPa)
    error = ITU_example_val - itur_val.value
    error_rel = error / ITU_example_val * 100  # (%)
